# blind-eval — сліпе порівняння відповідей моделей

Процедура, яку Архітектор 30.09 (DDL) шість разів збирав руками. Скрипт `blind_eval.py` поруч (лише stdlib, Python ≥ 3.10). Шлях після `sync.py`: `.claude/skills/blind-eval/blind_eval.py` у корені meta-репозиторію.

## Коли
- Порівняння моделей, версій промпта чи конвеєра за якістю відповідей, коли цифри мають вирішити вибір.
- Не для перевірки однієї відповіді на правильність — там досить звичайного рев'ю.

## 1. Пакет і ключ — засобами проєкту
Обв'язка проєкту (harness) видає **два окремі файли**:
- **пакет оцінювання:** джерело (або посилання на файли джерела) і відповіді під перемішаними літерами;
- **ключ:** `{item: {letter: label}}`.

Ключ і каталоги прогонів лежать **окремо** від пакета. Ідентифікатори елементів із префіксом виду (`e01` екстракція, `g01` генерація) дають зведення за видами.

## 2. Ізоляція й пошук витоків
```bash
python .claude/skills/blind-eval/blind_eval.py isolate --pack <run>/grade_pack.md --out <новий каталог> \
  --labels "flash-3.8,pro-3.1,qwen3,v1,v2"
```
- Копіює **лише пакет** у новий або порожній каталог. Каталог не може лежати всередині каталогу пакета. Якщо в пакеті є файл із назвою на кшталт ключа (`*key*`, `ключ*`), скрипт відмовляє й нічого не копіює.
- Шукає мітки (назви моделей і версій) як окремі слова без урахування регістру. Кожне влучання друкується з контекстом ±25 символів: `LEAK? file:line [label] '…'`. Exit 0 — чисто, 1 — є знахідки.
- **Кожне влучання розбирає Архітектор.** Назва пристрою чи плати («V2») — хибна тривога. Справжній витік («як Gemini Flash, я…») прибрати в пакеті, потім повторити `scan <каталог> --labels …`.

## 3. Оцінювачі — read-only субагенти
- Один субагент на **≤ ~30 елементів × 3 відповіді**. Більший обсяг ділиться на діапазони, кожен у свій `.jsonl`.
- Субагент читає **лише пакет і файли джерела**, на які той посилається. Ключі, прогони, звіти, task-файли й git йому заборонені. Пише тільки власний `.jsonl`.
- Промпт:
  ```bash
  python .claude/skills/blind-eval/blind_eval.py prompt --pack <iso>/grade_pack.md --out <iso>/grades_1.jsonl \
    --items "e01–e30" [--sources <каталог джерел>] [--rules-file domain_rules.txt] [--extra-fields honesty]
  ```
- Загальні правила промпта:
  - порожня відповідь правильна, коли в джерелі нічого немає;
  - вигадка — конкретний факт, якого немає в джерелі; переклад і переказ вигадками не є;
  - ідентифікатори порівнюються точно, символ у символ.
- Доменні правила — у `--rules-file`, по одному в рядку; вони нумеруються далі за загальними. Додатковий числовий критерій (`--extra-fields honesty`) визначається там же.
- Формат рядків:
  - на кожну відповідь — `{"item","letter","completeness","accuracy","usefulness",…,"fabrications":[…],"note"}`;
  - на кожен елемент — `{"item","best"}`; `"tie"` означає нічию.

## 4. Розкриття
```bash
python .claude/skills/blind-eval/blind_eval.py unblind --key <run>/key.json --grades <iso>/grades_*.jsonl \
  [--kind-prefix e=extraction,g=generation] [--strata sample.json --strata-field lang] [--diff flash-3.8,pro-3.1] \
  --save-to <постійний каталог>
```
- **Ключ** читається в трьох форматах: `{item:{letter:label}}`, `{"items":{…}}`, `{item:{"letters":{…}}}`.
- **Зведення за мітками:**
  - середні `completeness`, `accuracy`, `usefulness` і будь-яких інших числових полів (напр. `honesty`);
  - кількість вигадок і відповідей із вигадками;
  - перемоги за `best`.
- **Нічия** — `best`, якого немає серед літер елемента.
- **Види елементів** — за префіксом ідентифікатора (`--kind-prefix`). Без нього всі елементи йдуть однією групою.
- **Страти** (`--strata`) — окрема таблиця на кожне значення поля з файла вибірки.
- **Попарна різниця** (`--diff A,B`) — середня різниця A−B за кожним полем і лічильники «A краще / B краще / рівно».
- **Попередження** (дублікати оцінок, літери чи елементи поза ключем, неоцінені елементи) йдуть у stderr і в кінець зведення. **Прочитай їх до висновків.**

## 5. Збереження
Scratchpad стирається з перезапуском сесії. `--save-to` копіює ключ, усі `.jsonl` (і файл страт) у постійний каталог і пише `summary.md`. Шлях у scratchpad чи тимчасовому каталозі скрипт відхиляє (`--force` — свідомий виняток). Файли, що вже є там і відрізняються, він не перезаписує без `--force`.

## 6. Незалежність
Оцінює **не той**, хто писав промпт чи відповіді, що порівнюються. Виконавець, який налаштовував промпт моделі, і сам Архітектор, якщо він її налаштовував, — не оцінювачі. Субагент-оцінювач бачить лише ізольований каталог; ключ відкривається тільки на кроці 4.
